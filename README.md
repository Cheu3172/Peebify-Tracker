## What is this?

Peebify Tracker is where the community reports bugs and suggests features for [Peebify Launcher](https://peebify.net/). Everything is tracked in the [Issues](../../issues) tab, so it's easy to see what's known, what's planned, and what's been fixed.

## Before You Submit

- **Search first.** Check the [open issues](../../issues) and closed ones too. Your bug or suggestion may already be there, in which case add your details/logs instead of opening a new issue.
- **One issue per report.** Separate problems and separate suggestions are much easier to track and close.
- **Be specific.** A clear title and details/screenshots/logs get things fixed faster.

## Reporting a Bug

Include as much of the following as you can:

1. **What happened**, and what you expected to happen instead.
2. **Steps to reproduce**, in order, starting from opening the launcher.
3. **Launcher version** and branch (stable or beta).
4. **Which game** you were using, if it's game-specific.
5. **Screenshots or logs**, if you have them.

## Suggesting a Feature

Tell us:

1. **What you'd like**, described in a sentence or two.
2. **Why it would help**, meaning the problem it solves or how you'd use it.
